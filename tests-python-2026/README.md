# Tests Python 2026

Bo tai lieu va ma nguon Python phuc vu on tap, thuc hanh va tham khao.

## Noi dung du kien

- Cac tep `.py`: ma nguon bai tap, bai kiem tra va chuong trinh Python.
- Cac tep `.pdf`: de bai va tai lieu di kem.
- Cau truc thu muc duoc giu lai theo bo tai lieu goc.

## Cach su dung

1. Mo thu muc bai hoc can xem bang VS Code.
2. Chay tep Python bang lenh:

```bash
python ten_file.py
```

Mot so bai co the can thu vien ngoai hoac du lieu dau vao rieng. Hay doc de bai va ma nguon truoc khi chay.

## Luu y

Cac tep `.pyc` va thu muc `__pycache__` khong nen dua len GitHub vi day la cache co the tu tao lai.
